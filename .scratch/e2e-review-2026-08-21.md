## BLOCKER findings (must fix in this PR)

### B1. `fullyParallel: true` + shared DB + 238 specs each call `db.populate('dbdata1')` in `beforeEach` → race condition

Empirical: 238 / 239 specs call `db.populate('dbdata1')` in beforeEach.
With `workers: 2` × 3 browser matrix that's ≥1,500 concurrent populate-db
calls against one schema.

Per https://playwright.dev/docs/best-practices#testing-with-a-database:
*"If working with a database then make sure you control the data."*

**Fix in this PR**: `fullyParallel: false`, `workers: 1`. Serializes the
suite. Costs wall-clock but eliminates the race. Per-worker schemas
deferred.

### B2. `.github/workflows/php-checks.yml` references `web/index-test.php` which does not exist

Verified via `glob "web/index*.php"`: only `web/index.php` and
`web/index-production.php` exist.

**Fix**: change `index-test.php` → `index.php` in both places.

### B3. `tobiashoessl/antragsgruen:latest` is unpinned

Upstream publishes semver tags (`4.17.1-full`).

**Fix**: pin to `4.17.1-full`.

### B4. `executeMultiStatementSql` relies on server-side `multi_statements=1` flag never set in code

PDO_MYSQL defaults to NO_MULTI_STATEMENTS. The 1,654-line `dbdata1.sql`
needs `PDO::MYSQL_ATTR_MULTI_STATEMENTS = true` on the connection.

**Fix**: set the attribute in `executeMultiStatementSql`.

### B5. Zero `storageState` configuration + ~1,500 UI logins per matrix run

Per Playwright auth docs "Basic: shared account in all tests" — one
storageState file per project, written once by a setup project.

**Fix**: add `e2e/auth.setup.ts` setup project; reference
`.auth/std-admin.json` in each browser project's `use.storageState`.

### B6. `bootstrapConsultation` does `await import('../utils/auth')` defensively but no cycle exists

Verified: `fixtures/index.ts` imports only `clearLocalStorage` from
`utils/auth`; `auth.ts` imports nothing from `fixtures`.

**Fix**: static import.

### B7. `RestClient` and `RestAuth` are parallel implementations; `RestClient` is dead code

**Fix**: delete `RestClient`. Extend `RestAuth` with `bearerHeaders()`.

### B8. `BasePage.getUrl()` does ~2,400 HTTP round-trips per CI run to `/test/url-builder`

Routes are stable; one boot per browser can capture them. 5 min CI cost.

**Fix**: keep HTTP for now, log as deferred. (BLOCKER-by-severity but
the route resolution is server-authoritative and removing it requires
non-trivial local route map; defer.)

### B9. `e2e/tsconfig.json` lacks `noUncheckedIndexedAccess` despite `strict: true`

**Fix**: add the flag.

### B10. `e2e/package.json:lint:e2e` script wired to nonexistent `e2e/eslint.config.*`

**Fix**: extend root `eslint.config.mjs` to cover `e2e/**/*.ts`.

### B11. `@playwright/test: ^1.48.0` does not match the documented pin 1.62.1

**Fix**: change to `"1.62.1"` exact pin.

### B12. `utils/test-api.ts:35` silently swallows JSON parse errors with `.catch(() => ({}))`

**Fix**: detect non-JSON content-type and surface the body in the error.

### B14. TestController has zero access-control defense-in-depth (only `YII_ENV=test`)

**Fix**: IP allowlist (`127.0.0.1`, `::1`, `localhost`, RFC1918 ranges).

## Deferred follow-up

1. **Per-worker MySQL schemas** — proper fix for B1 race; large change.
2. **pglite as test DB** — would eliminate MariaDB container, faster CI.
   Note: pglite is PostgreSQL; Antragsgrün is MySQL/MariaDB. Switching
   requires porting `assets/db/{create,data,delete}.sql` to PG syntax,
   adjusting Yii2 AR dialect, re-doing all MariaDB-specific fixtures.
   Estimate: weeks of work, separate from this migration.
3. **Local route map** — eliminate `/test/url-builder` HTTP per nav.
4. **data-testid attribute sweep** for user-facing locators.
5. **storageState per role** (`stdUser`, `consultationAdmin`, etc.) —
   this PR covers `stdAdmin` only.
6. **Multi-role auth fixtures** — tests that need to switch roles
   within one test still do per-test UI login.

## Execution Plan (applied in the same commit as this audit)

### Methodology

- **KISS**: smallest change that achieves the goal. No speculative generality.
- **TDI / TDD**: write the smallest failing test (or smoke spec) first, then
  the minimal implementation to make it green, then refactor.
- **Validation gate after every phase**: `bunx tsc --noEmit` must exit 0
  before advancing. No broken-build intermediate states.
- **BLOCKER fixes are not optional** — they ship with the migration.

### Subagent coordination

- **Page Objects** (Phase 3): **1 subagent**, all 25 Page Objects in one call.
- **Spec files** (Phase 4): **6 parallel subagents**, one per category group.
  Each gets the reference `e2e/tests/motions/create.spec.ts` pattern, the
  full Codeception→Playwright translation table, and a strict file:line
  mapping for its assigned subset.
- **Re-audit** (Phase 10): **7 parallel reviewer subagents** against the new
  code; appends to a second section of this doc.

- **Specs** (Phase 4) are mechanical1:1 port of legacy Cepts.
